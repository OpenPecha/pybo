#
pybo

NLP for Tibetan, in Python.

	## Language
Python

	## Description
pybo is an open source library for Tibetan NPL. The word segmentation tool that tokenizes Tibetan text into words.

	## Installation

```bash
pip install pybo
```

Or from source:

```bash
git clone https://github.com/OpenPecha/pybo.git
cd pybo
pip install -e .
```
