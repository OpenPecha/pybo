# pybo

NLP for Tibetan, in Python

## Language

Python

## Description

pybo is an open source library for Tibetan NLP. It tokenizes Tibetan text into words.

## Installation

```bash
pip install pybo
```

## Usage

```bash
bo tok-string "༄༅། །རྒྱ་གར་སྐད་དུ།"
```
